# IvorySQL Line Avatars

`ivorysql-line-men.png` is a 1254 x 1254 sprite atlas generated and refined with the built-in image generation tool for this project on 2026-10-14. It contains a 6 x 6 grid of 36 original avatar illustrations. The final output file is used unchanged; each 209 x 209 cell is selected with CSS background positioning. Library order interleaves the hairstyle rows and face-shape columns, so adjacent choices have different silhouettes.

All portraits were visually reviewed for male appearance, a full normal head of medium-short hair, natural expressions and no facial hair. No photographs or real-person likenesses are used. Variation comes from hairstyles, glasses and clothing.

Generation prompt: create exactly 36 distinct male head-and-shoulder avatars in an exact 6-column by 6-row square grid without gutters, margins, headings, numbers or watermarks. Use a pure white background, bold simple minimalist black-and-white line art without shading or fine textures. Faces should occupy most of each cell and remain distinguishable at 40 pixels. Include six hairstyle groups: straight fringe, round natural curls, left side part, center part ending above ears, diagonal fringe, and broad soft waves. Vary broad round, narrow long, rectangular, square-jawed and oval faces, nose shapes, brows, head angles and clothing. All subjects are clean-shaven adult men with normal medium-short hair, no bald heads, buzzcuts, shaved sides, long hair, beards, moustaches, stubble, hats or feminine accessories. Maintain equal scale and safe cell padding for circular crops.

Refinement prompt: preserve the exact 6 x 6 atlas and hairstyles, strengthen face-shape differences, vary round, oval, rectangular, square and browline glasses, and remove all grid lines. Keep friendly normal expressions, black-and-white minimalist line art, no facial hair, and no text. The old atlas's fine hair texture and nearly identical faces were intentionally replaced. List portraits display at 40 pixels and featured portraits at 80 pixels.

Selected avatar URLs are stored in the existing `evangelist_participants.avatar_url` field as `/avatars/ivorysql-line-men.png#01` through `#36`. A missing or legacy value displays a stable default based on member id; a new member prefers an unused avatar. Reusing a tile is allowed after the library is exhausted or when explicitly chosen.
