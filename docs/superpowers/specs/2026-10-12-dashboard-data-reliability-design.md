# IvorySQL 看板数据可信与自动化设计

## 目标

让看板明确区分数据的统计日期、实际更新时间、采集来源和同步状态；修复已失效的自动采集任务；降低首页与内容页接口体积和加载时间；在不误删真实数据的前提下隔离早期演示数据。

## 范围

本阶段包含：

- 真实更新时间与数据日期展示。
- 平台级新鲜度、同步状态和错误信息。
- 掘金停止同步后的提醒关闭。
- ITPUB、墨天轮采集器修复，思否任务监控补全。
- 首页、社媒页、内容页接口瘦身和服务端分页。
- 演示数据识别、备份、隔离和后续删除机制。
- README 中自动化、数据库和贡献者统计口径的同步修正。

本阶段不包含：

- 自动获取公众号和视频号后台数据。
- 自动修改文章分类或来源。该能力在数据基础稳定后单独实现。
- 更换数据库或认证系统。

## 数据可信模型

### 数据日期与更新时间

所有面向用户的数据卡片至少携带以下两个时间概念：

- `data_date`：指标对应的统计日期。
- `updated_at`：最近一次成功写入或刷新时间。

顶部“最后更新”不再使用浏览器当前日期，而是展示当前页面核心数据中最近一次成功更新时间。平台卡片显示自己的数据日期；回退到历史最新值时明确标记“最新可用数据：YYYY-MM-DD”，不得显示为当前筛选日期。

### 同步运行记录

新增 `sync_runs` 表：

- `id`
- `platform`
- `started_at`
- `finished_at`
- `status`：`running`、`success`、`failed`
- `records_seen`
- `records_written`
- `error_message`
- `trigger`：`vercel_cron`、`ego_lite`、`manual`

每个同步入口都记录运行结果。后台提醒基于最近一次成功运行，而不是仅依赖文章写入时顺带更新的 `reminder_settings`。

### 演示数据隔离

禁止在生产环境直接运行随机种子脚本，除非显式设置 `ALLOW_SAMPLE_DATA=1`。

对现有数据采用两阶段处理：

1. 只读审计脚本按平台、日期、值域和已知随机序列生成候选清单，不修改数据。
2. 审核后将候选行复制到 `quarantined_sample_data`，再从业务表删除。删除操作必须在单个数据库事务内完成，并输出每张表的备份和删除数量。

第一轮实施只提供审计与隔离工具，不按日期整段删除，避免误伤同日后来导入的真实数据。

## 自动化边界

### 保持自动

- GitHub 仓库指标、贡献者活动、Release 与 Docker Hub 下载量。
- CSDN、博客园、思否。
- ego-lite：开源中国、51CTO、头条号、知乎。

### 修复后自动

- ITPUB：根据当前作者主页结构重新提取最近 50 篇。
- 墨天轮：将用户统计和文章指标解析从脆弱的页面正则改为当前公开数据接口或嵌入状态数据。

### 保持人工

- 公众号、视频号。
- 掘金历史数据只读，不再同步，不再提示过期。

## API 与性能

### 首页

首页使用新的轻量摘要接口，只返回页面实际展示的字段。贡献者月度明细、文章详情和完整下载历史不进入首页响应。

### 内容页

拆分为：

- 平台汇总：文章数、总阅读量、最新数据日期、更新时间。
- 文章分页：`platform`、`page`、`pageSize`、可选搜索与分类筛选。

默认每个平台只加载汇总；用户展开某个平台后才获取第一页文章。导出使用独立流式或完整导出接口，不复用页面列表接口。

### 社媒与官网

接口返回每个平台的 `data_date` 和 `updated_at`，不静默把历史数据伪装成筛选日期。官网没有当天数据时展示空状态和最近可用日期。

## 后台体验

新增“同步状态”区域，按平台展示：

- 最近成功时间。
- 最近运行状态。
- 写入数量。
- 最近错误。
- 自动或人工来源。

失败任务可由管理员手动重试。普通查看用户不显示新增、编辑、删除和同步按钮。

## 迁移与兼容

- 数据库迁移采用现有 `CREATE TABLE IF NOT EXISTS` 和 `ALTER TABLE ... IF NOT EXISTS` 方式，兼容当前启动初始化流程。
- 现有 `reminder_settings` 暂时保留，页面迁移完成后只负责提醒策略。
- 所有现有文章、活动和贡献者数据原样保留。

## 验收标准

- 顶部更新时间来自数据库，不再永远显示今天。
- 当平台数据过期时，页面明确显示真实数据日期。
- ITPUB 与墨天轮各能成功同步最近文章或给出可理解的失败原因。
- 掘金不出现在过期提醒中。
- 首页接口不超过 100 KB，正常线上响应目标低于 2 秒。
- 内容首屏不下载全部文章；分页请求只返回当前页。
- 所有同步均能在后台看到成功或失败记录。
- 演示数据工具默认只审计，未经显式执行不会删除任何生产数据。
