# IvorySQL 活动素材中心设计

## 目标

把活动页面从活动统计列表升级为可检索的活动档案。用户从活动卡片进入站内详情页后，可以查看官网原文、现场照片、宣传海报、PPT、视频回放和其他资料；管理员可以补充官网未公开的材料。

## 使用方式

### 活动列表

- 保留活动总数、参与人数、报名人数和线上观看统计。
- 支持年份、活动类型和关键词筛选。
- 往期活动使用分页，不再一次渲染全部 30 条以上记录。
- 卡片显示素材摘要，例如“12 张照片、1 份 PPT、1 个回放”。
- 点击卡片进入 `/events/[id]`，官网原文作为次要外链。

### 活动详情

详情页包含：

- 名称、日期、类型、地点、场馆、描述和参与数据。
- 宣传海报预览。
- 现场照片网格与大图查看。
- PPT、视频回放、新闻稿和其他附件列表。
- 素材来源和获取方式。
- IvorySQL 官网原文入口。

公开 URL 可以直接打开。只有领取说明、没有公开地址的 PPT，显示“公众号回复 HOW2026 获取”等说明，不伪造下载按钮。

## 数据结构

新增 `activity_materials` 表：

- `id`
- `event_id`，外键关联 `activity_events`
- `material_type`：`photo`、`poster`、`ppt`、`video`、`article`、`other`
- `title`
- `url`，允许为空
- `thumbnail_url`
- `access_note`，用于记录公众号关键词等领取方式
- `source_url`
- `sort_order`
- `created_at`
- `updated_at`

素材文件不存入 PostgreSQL。第一版保存官网或云盘 URL；后续需要直接上传时接入 Vercel Blob，并继续复用同一张表。

现有 `activity_events.collected_data` 保留，用于来源、结束日期等非固定采集字段，不再承担素材数组的主存储职责。

## 官网自动同步

新增每日活动同步任务：

1. 读取 IvorySQL 中文活动列表全部分页。
2. 以官网活动详情 URL 作为稳定唯一标识进行 upsert。
3. 同步名称、日期、类型、地点、描述和官网链接。
4. 读取活动详情页，提取正文图片和公开链接。
5. 将图片按上下文分类为海报或现场照片；无法确定时标记为 `photo`，管理员可修改。
6. 识别公开视频、PPT 和文章链接。
7. 对仅有文字领取方式的资料写入 `access_note`。

自动同步只新增或更新官网来源的字段，不覆盖管理员手工填写的参与人数、报名人数、观看人数和手工素材。

## 后台管理

活动管理表单增加素材编辑区：

- 选择素材类型。
- 填写标题、链接、缩略图、来源和获取说明。
- 调整排序。
- 删除单条素材。

第一版不引入二进制文件上传，避免存储费用和上传权限扩大。后台可以粘贴公开链接或云盘链接。

## 权限

- 查看用户只能浏览、筛选和打开素材。
- 管理员可以新增、编辑、删除活动及素材，并手动触发官网同步。
- API 继续由现有代理层保护，页面通过认证上下文隐藏无权限操作。

## 失败与数据质量

- 官网结构变化导致解析失败时保留现有活动和素材，不做清空。
- 同步任务记录到统一的 `sync_runs` 表。
- 相同活动 URL 和相同素材 URL 不重复创建。
- 外链失效只标记不可用，不自动删除素材记录。

## 验收标准

- 现有 30 条活动不丢失。
- 活动列表支持筛选和分页，移动端不再形成超长单页。
- 每个活动都有站内详情入口。
- 详情页可以按类型浏览照片、海报、PPT、视频和其他链接。
- 官网活动可以每日自动新增或更新，重复运行不产生重复活动或素材。
- 管理员可以补充公开链接和公众号领取说明。
- 普通查看用户看不到编辑、删除、新增和同步按钮。
